Every one of the 34 themes is put through the same checks before it ships:

- **WCAG 2.1 contrast** — editor text, comments, and sidebar text all clear 4.5:1 against their background.
- **Color-vision-deficiency audit** — every pair of syntax colors that sits next to real code is simulated under protanopia, deuteranopia, and tritanopia.
- **PCA + dendrogram** — which themes look like each other overall, built from each theme's full 13-role syntax palette in CIE Lab space.
